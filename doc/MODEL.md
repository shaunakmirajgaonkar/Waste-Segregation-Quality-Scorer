# Model and Computer-Vision Methodology

## Default Engine

The application uses a lightweight local computer-vision engine based on OpenCV and NumPy.

## Techniques

- K-Means clustering
- HSV analysis
- Canny edge detection
- Color heuristics

## Categories

- Recyclable
- Organic
- Trash
- Hazardous

## Optional CNN

A trained Keras model can be placed in the project root as waste_model.h5.
