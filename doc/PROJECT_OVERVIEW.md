# Project Overview

## Waste-Segregation Quality Scorer

Waste-Segregation Quality Scorer is a local computer-vision desktop application that analyzes waste images and estimates segregation quality.

## Objectives

- Analyze waste images locally.
- Estimate waste categories.
- Calculate Purity Score.
- Assign a quality grade.
- Detect contamination.
- Provide recommendations.
- Maintain scan history.

## Technologies

- Python
- Tkinter
- OpenCV
- NumPy
- Pillow
- Optional TensorFlow/Keras
