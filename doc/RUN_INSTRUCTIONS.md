# Run Instructions

## Setup

    python3 -m venv .venv
    source .venv/bin/activate

## Install

    pip install -r requirements.txt

## Run

    python waste_scorer_app.py

## Workflow

1. Launch the application.
2. Upload a waste image.
3. Click Analyze.
4. Review the Purity Score.
5. Review category scores.
6. Review contamination alerts.
7. Review improvement recommendations.
8. Review scan history.
